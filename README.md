# ScamBrake – Pause Before You Trust 🚨

An AI-assisted, voice-first cyber fraud detection assistant for Hindi and Indian English users.

## About the Project

ScamBrake helps users identify potentially fraudulent messages and audio before they become victims of cyber scams. It analyses suspicious communication, highlights warning signs, assesses risk and provides situation-specific safety guidance.

## Key Features

- **Multilingual Analysis:** Analyse suspicious messages in Hindi and Indian English.
- **Audio Transcription:** Convert uploaded audio into text using Gnani AI Prisma.
- **Risk Detection:** Identify HIGH, MEDIUM and LOW risk communication.
- **Warning Signs:** Highlight suspicious phrases and explain potential scam tactics.
- **Scam Replay Lab:** Explore scam scenarios and understand their warning signs.
- **Recovery Assistant:** Get practical safety steps based on the situation reported by the user.
- **Voice Guidance:** Listen to safety instructions.

## Getting Started

### Prerequisites
- Node.js installed
- Required API credentials

### Installation

1. Clone the repository:

   `git clone https://github.com/harshitachuphal/ScamBrake.git`

2. Open the project folder:

   `cd ScamBrake`

3. Install dependencies:

   `npm install`

4. Create a `.env` file in the root directory and add the required API credentials using the variable names expected by the application.

5. Start the server:

   `node server.js`

6. Open your browser:

   `http://localhost:5000`

## Project Structure

- `server.js` – Backend and API routes
- `public/` – Frontend files
- `package.json` – Project dependencies
